
# Titanic Dataset Data Cleaning

## Project Overview
This project focuses on cleaning a real-world Titanic dataset using Python and Pandas.

## Objectives
- Load Titanic CSV dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Convert categorical columns into appropriate data types.
- Save the cleaned dataset into a new CSV file.

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Files
- titanic.csv – Original dataset
- data_cleaning.ipynb – Python implementation
- cleaned_data.csv – Cleaned dataset

## Result
Successfully performed data cleaning operations and generated a cleaned CSV dataset.
